# Organizaciones

Las organizaciones interesadas en recibir donaciones pueden solicitarlo via correo electrónico a nhk punto web arroba gmail punto com.

Cualquiera puede sugerir una organización, ONG, asociación civil para que reciba la donación de cada torneo al correo electrónico del párrafo anterior o sumándose al equipo [Memorial Margarita](https://lichess.org/team/memorial-margarita) en Lichess y comentándola en el foro (para que no se repitan y quede público).

La aceptación o rechazo de las organizaciones es a **total** discrecionalidad del organizador, aunque cada negativa tendrá su justificación.

## Requisitos

1. que puedan recibir donaciones por transferencia bancaria, y
2. que puedan emitir algún tipo de comprobante para demostrar que la donación fue realizada (se incluirá obviamente el comprobante de transferencia)
3. deben ser de Argentina
